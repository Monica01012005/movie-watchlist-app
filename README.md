# 🎬 Movie Watch App

A full-stack MERN (MongoDB, Express, React, Node.js) application where users can browse movies, view details, and manage their watchlist.

---

## 🚀 Features

- 🔐 User Authentication (Login / Register)
- 🎥 Browse Movies
- 🔍 Search Movies
- ⭐ Add to Watchlist / Favorites
- 📄 Movie Details Page
- 📱 Responsive UI
- ⚡ Fast API with Express & Node.js

---

## 🛠️ Tech Stack

**Frontend:**
- React
- Axios
-  Tailwind (if used)

**Backend:**
- Node.js

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git  
cd mern-final-setup

---

### 2️⃣ Install dependencies

#### Install server dependencies
cd mern-backend 
npm install  

#### Install client dependencies
cd my-app 
npm install  

---

### 3️⃣ Setup environment variables

Create a `.env` file in the **server** folder:

MONGO_URI=your_mongodb_connection_string  
PORT=5000  
JWT_SECRET=your_secret_key  

---

### 4️⃣ Run the application

#### Start backend
cd mern-backend 
node server.js 

#### Start frontend
cd my-app 
npm run dev  

---

## 🌐 App Flow

1. User registers or logs in  
2. Browse or search for movies  
3. Click on a movie to view details  
4. Add/remove movies from watchlist  
5. Data is stored in MongoDB
